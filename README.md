# Império da Confeitaria

Jogo mobile Android de produção e gestão de uma confeitaria. Após instalar, jogue offline; o progresso fica salvo no aparelho.

## Baixar e instalar

[**Baixar APK Android — versão mais recente**](https://github.com/samulzz/imperio-da-confeitaria-downloads/releases/latest/download/Imperio-da-Confeitaria.apk)

1. Baixe o APK e abra o arquivo no Android.
2. Se solicitado, permita a instalação de aplicativos por este navegador.
3. Instale e abra **Império da Confeitaria**.

Para atualizar, instale o novo APK por cima da versão anterior. Não desinstale o aplicativo se quiser preservar o progresso.

Requisitos: Android 7 ou superior, aparelho com suporte a aplicativos ARM64 ou x86_64. Internet necessária somente para baixar e atualizar.
